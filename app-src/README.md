# Исходники приложения

- `ui-source.html` — интерфейс, общий для веб-версии и приложения.
- `make_html.py` — собирает из него `assets/index.html` для APK и `index.html` для автообновления.
- `src/`, `res/`, `AndroidManifest.xml` — Android-обёртка: WebView, хранение данных, файл настроек, проверка обновлений.
- `build.sh` — сборка и подпись APK. Ключ подписи (`barorders-key.jks`) и пароль от него в репозиторий не кладутся, они хранятся у владельца. Пароль передаётся через переменную `KS_PASS`.

Чтобы обновить только интерфейс: поменять `ui-source.html`, увеличить `build` в `version.json`, собрать `index.html` и залить в `main`. Приложение подхватит его само.
