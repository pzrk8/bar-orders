# Заказы на бар

Приложение для Android: каталог позиций бара, корзина и готовые тексты заказов для каждого поставщика.

- **Скачать приложение:** [apk/zakazy-na-bar.apk](apk/zakazy-na-bar.apk) (на странице файла нажмите «Download raw file»).
- `index.html` — интерфейс приложения. Приложение само проверяет его при запуске и предлагает обновиться.
- `version.json` — номер текущей сборки интерфейса.

Каталог, поставщики и заказы хранятся только на телефоне, в этом репозитории их нет.
Резервная копия делается в приложении: «Настройки» → «Файл настроек».
